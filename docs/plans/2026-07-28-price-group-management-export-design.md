# 每日价格分组管理与选择导出设计

## 目标

在现有单文件价格工具中，为当前选中的每日价格记录增加分组增删与恢复默认能力，并让图片导出可以临时选择需要包含的分组。所有每日分组修改继续保存在浏览器本地；图片导出选择不持久化。

## 交互结构

每日价格视图顶部新增 `管理分组` 按钮。点击后打开原生 `<dialog>`：

- 列出当前日期的全部分组。
- 每行提供删除按钮；删除需要确认，确认后立即写入当前日期的 `groups` 并保存。
- 提供新增表单，字段为类型、分组名称、美元价格和可选说明。
- 类型和名称必填，美元价格必须为非负数。
- 分组 ID 由工具生成，保证在当前日期和历史日期中不会与已有 ID 冲突。
- 提供 `恢复默认` 操作并二次确认。

图片导出改为先打开 `选择导出分组` 对话框：

- 每次打开都基于当前日期重新生成列表并默认全选。
- 支持全选、清空以及逐项勾选。
- 未选择任何分组时禁用导出确认按钮，并显示选中数量。
- 确认后仅把所选分组传入 Canvas 绘制流程。
- 勾选状态不进入应用 `state`、`localStorage` 或 JSON 备份。

## 数据模型

每日记录仍使用现有 `groups` 数组：

```js
{
  id: "custom-1",
  category: "语言分组 · 自定义",
  name: "custom - model",
  price: 0.01,
  note: "可选说明"
}
```

新增核心函数：

- `createPriceGroup(input, days)`：校验输入并生成唯一 ID。
- `removePriceGroup(day, groupId)`：从当前日期移除指定分组。
- `restoreDefaultGroups(day)`：恢复内置 12 个分组。
- `filterPriceComparison(model, selectedIds)`：为图片导出生成过滤后的比较模型。

内置分组定义从历史数据构造逻辑中抽出为不可变模板。恢复默认时：

1. 按稳定 ID 查找当前日期已有的内置分组。
2. 已存在的内置分组保留当前美元价格。
3. 之前删除的内置分组使用内置默认价格与说明补回。
4. 自定义分组被移除。
5. 日期、行情、每日备注、官网与下游配置不变。

## 自动保存

新增、删除、恢复默认完成后立即调用现有 `persist()`，重新渲染每日价格表和分组管理对话框。刷新页面后分组修改仍然存在。

由于现有状态校验已允许可变长度的 `groups`，只需增强每个分组的字段校验，并确保同一天的 ID 不重复。旧版本本地数据仍可继续加载。

## 图片导出

Canvas 导出函数接受所选 ID 集合。绘制前使用过滤后的比较模型计算：

- 图片表格行数。
- Canvas 总高度。
- 各行价格变化颜色和文本。

导出顺序与当前价格表顺序一致。未选择任何分组时不会创建下载。

## 视觉与可访问性

两个对话框延续当前中性灰白财务工作台风格，边框与按钮保持紧凑。删除使用红色垃圾桶图标按钮并提供文本提示；新增和恢复默认是明确命令。

对话框支持 Escape 关闭、键盘焦点、明确标题和关闭按钮。导出复选框使用原生控件，状态不只依赖颜色。

## 测试

- 单元测试覆盖唯一 ID、新增校验、删除、恢复默认保价与补回规则、过滤导出模型。
- 浏览器测试覆盖新增后刷新仍存在、删除后刷新仍不存在、恢复默认回到 12 个分组。
- 浏览器测试覆盖导出对话框默认全选、取消部分分组后 PNG 高度减少、重新打开后恢复全选、空选择禁止导出。
- 桌面和手机视口检查两个对话框不溢出、文字不遮挡。
