# 中转站价格与 Stripe 盈利计算工具设计

## 目标

将 `/Users/fatballfish/Documents/中转站每日价格表.xlsx` 中除 `Sheet1` 外的价格历史与计算逻辑重写为一个可离线使用的单文件 HTML 工具。工具不接入 Sub2API 后端，所有数据仅保存在当前浏览器，并支持 JSON 备份与恢复。

## 交付形态

- 最终用户只需打开 `tools/relay-pricing-calculator.html`。
- HTML 内嵌样式、脚本、图标、默认历史数据与 PNG 导出逻辑。
- 不依赖 CDN、构建服务、网络请求或后端接口。
- 开发测试可以使用独立测试文件，但不属于运行时依赖。

## 信息架构

应用顶部使用三个视图标签：

1. `每日价格`：维护历史、复制新日期、编辑价格并导出公告图片。
2. `Stripe 收款`：查看 `$1-$50` 收款损耗，并计算任意美元金额。
3. `盈利模板`：维护多套成本/售价模板，并查看不同充值档位的利润表现。

全局工具区提供汇率、Stripe 比例费率、固定手续费、JSON 导入导出与恢复初始数据。汇率默认 `1 USD = 6.8 CNY`，Stripe 默认 `2.9% + $0.30/笔`。

## 每日价格数据

内置 Excel 中 2026-07-22 至 2026-07-26 的历史。每日完整版本包含以下 12 个分组：

- `gpt - regression`
- `gpt - offer`
- `gpt - normal`
- `gpt - stable`
- `claude - offer`
- `grok - offer`
- `opensource - openai`
- `opensource - claude`
- `gpt - image - low`
- `gpt - image - medium`
- `gpt - image - high`
- `grok - image`

每条记录使用稳定 ID 对比前一天。语言和开源模型以倍率作为美元主输入，人民币换算为 `美元价格 × 汇率`。生图分组以每张美元价格作为主输入，并保留分辨率与画质说明。

复制操作默认复制当前选择日期，日期推进一天。用户可以修改日期、行情、备注、官网地址、下游配置说明以及各分组价格。删除日期需要二次确认，至少保留一天历史。

## 价格变化规则

当前日期按时间顺序寻找最近的上一条历史记录，并按稳定分组 ID 对比美元价格：

- 当前价格大于上一日：涨价，浅红背景。
- 当前价格小于上一日：降价，浅绿背景。
- 价格相同：持平，中性灰背景。
- 上一日没有该分组：新增，浅黄背景。

编辑表和导出图片使用同一比较函数，防止颜色口径不一致。界面和图片均显示图例与变化幅度。

## Stripe 计算

令充值金额为 `amount`，比例费率为 `rate`，固定手续费为 `fixedFee`：

```text
手续费 = amount × rate + fixedFee
实际收款 = max(0, amount - 手续费)
损耗率 = 手续费 ÷ amount
收款率 = 实际收款 ÷ amount
```

`理应收款金额` 等于用户充值金额，`实际收款金额` 为扣除 Stripe 手续费后的净到账。默认列表展示整数 `$1-$50`，自定义计算器接受大于 0 的任意金额。无效、空值和非正数不进入计算。

## 盈利模板计算

每个模板包含名称、美元成本单价和美元销售单价。所有价格输入旁边即时显示按全局汇率换算后的人民币价格。

对于充值档位 `amount`：

```text
每 $1 额度可用量 = 1 ÷ 销售单价
每 $1 额度实际成本 = 每 $1 额度可用量 × 成本单价
表面盈利率 = (1 - 每 $1 额度实际成本) ÷ 1
档位总实际成本 = amount × 每 $1 额度实际成本
档位实际收款 = max(0, amount - amount × Stripe 比例费率 - 固定手续费)
实际盈利额 = 档位实际收款 - 档位总实际成本
实际盈利率 = 实际盈利额 ÷ 档位实际收款
```

实际收款为 0 时，实际盈利率显示为不可计算。列表展示 `$1-$50`，并以红、黄、绿区分亏损、低利润与健康利润。模板支持新建、复制、重命名和删除，至少保留一个模板。

## 本地数据与恢复

应用状态以带版本号的 JSON 结构写入 `localStorage`。每次有效编辑后保存。启动时若数据缺失或损坏，则使用内嵌默认数据并展示非阻断提示。

JSON 导出包含全局参数、每日历史、盈利模板与当前视图。导入时校验版本、必要字段、数值范围和日期格式，验证通过后整体替换并保存；验证失败时保持原数据不变。恢复初始数据需要二次确认。

## 图片导出

使用原生 Canvas 绘制固定宽度 PNG，不依赖 DOM 截图库。图片包含：日期标题、分组表、美元价格、人民币换算、变化颜色与幅度、汇率、行情、备注、官网和下游配置说明。编辑按钮、标签页和本地管理控件不会出现在图片中。

Canvas 根据文本测量自动换行和计算高度，保证长行情与说明不被截断。导出文件名格式为 `中转站价格-YYYY-MM-DD.png`。

## 视觉设计

采用紧凑的财务工作台风格：暖白背景、墨黑结构线、少量蓝色用于可编辑输入，红/绿/黄仅表达业务状态。标题使用本机宋体类字体，正文使用本机中文无衬线字体。桌面端保持高信息密度，移动端保留固定工具栏并允许表格横向滚动。

不使用装饰性卡片堆叠、大面积渐变或营销式页面结构。按钮优先使用熟悉图标和短命令文本，危险操作明确区分并二次确认。

## 错误处理与可访问性

- 数字输入设置合理的最小值与步进，并在计算层再次校验。
- 保存、导入、导出失败以页面内提示反馈，不使用静默失败。
- 标签页、按钮、输入框和对话框支持键盘操作与可见焦点。
- 表格表头固定，颜色状态同时提供文字/符号，避免只依赖颜色传达含义。
- PNG 导出失败时保留当前数据并给出可重试提示。

## 验证范围

- 单元测试覆盖 Stripe 费率、人民币换算、利润公式、前一日匹配和涨跌分类。
- 浏览器测试覆盖初始加载、复制日期、模板管理、本地持久化、JSON 备份恢复和 PNG 下载。
- 在桌面与手机视口检查文字截断、表格滚动、按钮可达性和控件重叠。
- 对 Excel 中 `$1`、`$10`、`$30` 代表性档位进行数值对账，并扩展验证到 `$50`。
